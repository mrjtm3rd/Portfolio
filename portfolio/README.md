# Creative Portfolio (Next.js + Tailwind)

## Run it
    npm install
    npm run dev

Open http://localhost:3000

## Add your images (optional)
- `public/hero.jpg`   full-screen hero photo (dark photos work best)
- `public/nav-bg.jpg` texture behind the nav bar (falls back to flat grey)

## Edit content
Everything lives in `data/content.js`: contact details, education, skills, experience, projects.
